# magical-industries

Landing page for [magical.industries](https://magical.industries).

Shows the Magical Industries logo and name, then redirects visitors to
[magical.enterprises](https://magical.enterprises).

## Local preview

Open `public/index.html` in a browser, or serve the `public/` directory:

```bash
npx serve public
```

## Deploy

Pushing to `main` deploys `public/` to GitHub Pages via GitHub Actions.
